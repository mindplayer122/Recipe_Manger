# Recipe_Manger

A simple Python recipe manager built with Streamlit. The application allows users to add, view, search and delete recipes.

## Live Demo 

[view the live demo](https://8t9qe9r3dhfkvhmccdmro5.streamlit.app)

## Features

- Add recipes
- View saved recipes
- Search recipes by title or ingredient
- Delete recipes
- Store recipes in a JSON file


## Technologies Used

- Python
- Streamlit
- JSON
- Git
- GitHub

## How to Run Locally

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install the required dependencies.
4. Run the Streamlit application.

### Install dependencies

```powershell
py -m pip install -r requirements.txt
```

### Run the application

```powershell
py -m streamlit run app.py
```
